# Description

Signal Loom Infographics makes source-bound infographics from supplied research, reports, notes, and data. It turns that material into a semantic, responsive web artifact while keeping sources, claims, uncertainty, story structure, representation choices, and review state inspectable in a resumable Loomfile.

Requested derivatives can include carousels and other platform-native forms. It does not invent evidence, independently establish truth, approve its own work, or publish without human authority.

# Usage Notes

Copy the .zip from "Additional Files" to your Codex, Claude Code, or other harness, or add the .zip to a project knowledge base in Chat. Attach or reference the .zip in chat and say, "Install this Augment." The prompt in this post is optional. For a manual skill installation, extract its one-root `signal-loom-v0.1.1` folder into your Codex or Claude Code personal skills directory as `signal-loom`. The complete repository archive is the supported package for both hosts. Run `python scripts/self_check.py`, refresh or restart the host, confirm `signal-loom` is listed, and invoke `$signal-loom` in Codex or `/signal-loom` in Claude Code. The prompt in this post provides clean-install checks and light onboarding but is not required.

- Bring the source material, intended audience, desired decision or action, and any brand, accessibility, format, or publication constraints.
- The default deliverable is a semantic responsive web infographic; request carousels or platform-native derivatives explicitly.
- Treat built, reviewed, approved for export, and published as separate states. Static checks do not prove factual accuracy, rendered accessibility, security, or professional fitness.

Public GitHub Repo: [signal-loom](https://github.com/Stunspot/signal-loom)
